# Python Automation & Data Pipelines (ETL)

A collection of custom Python scripts designed for task automation, data cleaning, web scraping, and file processing.

---

## 🚀 Featured Projects

### 1. Multi-Source ETL Pipeline
* **Description:** Extracts raw data from multi-format files (Excel, CSV), cleans missing values, and loads structured records into a clean output format.
* **Tech Stack:** Python, Pandas, NumPy, SQLAlchemy.

### 2. Web Data Extractor & Storage
* **Description:** Scrapes structured product/listing data from web pages, handling HTTP requests and formatting clean report exports.
* **Tech Stack:** Python, BeautifulSoup, Requests, Pandas.

### 3. File Processing Utility
* **Description:** Automates batch file management, filtering, renaming, and text parsing to replace repetitive manual tasks.
* **Tech Stack:** Python, OS, Pathlib, PyPDF.
